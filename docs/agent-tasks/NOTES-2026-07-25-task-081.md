## 11. F7 clip measurement: counting pixels was itself a false green

Counting bright *pixels* across the same-pose frame pair showed only a -11% change
(1205 -> 1077) and would have supported "the clip barely bites". Counting distinct
4-connected *blobs* — i.e. stars actually drawn — showed **107 -> 28**, a 74% cut. The
survivors are the near stars, which are large and saturated, so they dominate the pixel
count. Switched the metric to blobs and recorded the trap in the research doc.

Before/after on the same statistic: **13 -> 0 blobs** (total extinction) becomes
**107 -> 28 blobs** with max luma 255 -> 255.

## 15. CONTRADICTION WITH THE SPEC — the "bit-identical proof" test has no power

**Reported, not worked around** (global rule 1). The spec states, twice and emphatically:

> The `ctx === 'galaxy'` early return is **required**, not an optimization: it guarantees the
> exact `1.0` the bit-identical requirement depends on.

and for Deliverable 4's assertion:

> This assertion IS the bit-identical proof; treat it as the gate.

**Both are false.** Mutation test — deleted the early return from `pcScales`, ran the suite:
all 6 `pcScales` tests pass, including `expect(s.unitsToPc).toBe(1)`. Reason:
`CONTEXT_UNIT_METERS.galaxy / CONTEXT_UNIT_METERS.galaxy` is `x / x`, which is **exactly 1**
in IEEE-754 for any finite non-zero `x`. Checked the spec's specific fear (a "ratio-of-ratios
landing on 0.9999999999999999") against four plausible refactor shapes — `(G/S)/(G/S)`,
`1/(1/(G/G))`, `(1/(S/G))*(S/G)` — all return exactly 1.

What this does and does not change:

- **The bit-identical requirement itself is still satisfied.** Galaxy context does get exactly
  `1.0`. That was never in doubt and the e2e/census evidence backs it.
- **The early return is intent/readability, not a correctness guard**, and no test can
  distinguish its presence. I **kept it** (harmless, and it documents the intent), but the
  comments in `context-scale.ts` and `context-scale.test.ts` currently assert a guarantee they
  do not provide.
- The real bit-identity evidence is the measured pair: `?debug=shaderjitter` unchanged and the
  galaxy-context full-canvas census unchanged (§8, §9).

**Not fixed unilaterally** — rewriting a rationale the spec states as a closed decision is the
spec's call, not the executor's. Proposed edit: soften both comments to "exactly 1 by
construction; the early return states the intent — the IEEE-754 identity `x/x === 1` is what
actually guarantees it", and stop calling the assertion the gate.
